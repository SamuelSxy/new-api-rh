# 控制台使用手册

> 本手册适用于所有角色。系统共有四种角色：**访客**（未登录）、**普通用户**（role=1）、**管理员**（role=10）、**超级管理员**（role=100）。  
> 以下按"普通用户"和"管理员/超级管理员"两大视角分章说明。

## 2. 普通用户功能

登录后即可访问，无需任何特殊权限。

### 2.1 仪表盘 `/dashboard`

- **概览（Overview）**：查看自己的 API 调用量、余额消耗趋势图。
- **模型用量（Models）**：按模型分类查看使用情况。

### 2.2 Playground `/playground`

在线测试 API 的沙盒环境，可选择模型、调整参数、发送测试请求，查看原始响应。

### 2.3 聊天 `/chat`

基于预设配置的聊天交互界面，支持多会话管理。

### 2.4 Studio `/studio`

多模态创作工作室，支持文生图、图生图等绘图任务，可查看历史资产。

### 2.5 API 密钥 `/keys`

- 创建、查看、重命名、删除个人 API Token。
- 设置 Token 的有效期、配额上限、IP 白名单等。

### 2.6 使用日志 `/usage-logs`

- **调用日志（Common）**：查看自己全部 API 调用记录（时间、模型、Token 用量、费用）。
- **任务日志（Task）**：查看绘图等异步任务的执行记录与状态。

### 2.7 钱包 `/wallet`

- 查看当前余额与充值记录。
- 通过支付渠道（Epay / Stripe / Creem / Waffo 等，视系统配置）进行充值。
- 输入兑换码抵扣额度。

### 2.8 个人资料 `/profile`

- 修改昵称、头像、邮箱、密码。
- 绑定 / 解绑 GitHub、Discord、OIDC 等 OAuth 账号。
- 配置 TOTP 两步验证（2FA）。
- 管理 Passkey（生物识别 / 硬件密钥）。
- 查看推荐邀请码（AFF）。
- 每日签到（如系统开启）。

## 3. 管理员功能

需要 `role ≥ 10`。在导航侧边栏中会显示管理员专属区域。

### 3.1 渠道管理 `/channels`

管理上游 AI 服务提供商的接入配置。

| 操作 | 说明 |
|------|------|
| 新增渠道 | 填写 API Key、基础 URL、渠道类型（OpenAI / Claude / Gemini 等） |
| 编辑 / 删除 | 修改或移除现有渠道 |
| 连通性测试 | 向渠道发送测试请求，检查可用性 |
| 余额查询 | 自动拉取渠道账户剩余额度 |
| 标签分组 | 为渠道打标签，便于按组路由 |
| 上游同步 | 从上游提供商拉取最新支持的模型列表 |
| 启用 / 禁用 | 快速切换渠道可用状态，不影响配置 |

### 3.2 模型管理 `/models`

- 维护模型元数据（名称、别名、分类、图标）。
- 与上游渠道同步，新增或更新模型映射关系。

### 3.3 用户管理 `/users`

| 操作 | 说明 |
|------|------|
| 查看用户列表 | 搜索、分页浏览所有注册用户 |
| 编辑用户 | 修改用户资料、余额、分组、角色 |
| 封禁 / 解封 | 限制或恢复指定用户的访问 |
| 充值 | 为用户手动添加配额 |
| 重置 Passkey | 清除用户的 Passkey 记录 |
| 查看充值记录 | 查看指定用户的历史充值明细 |

### 3.4 兑换码管理 `/redemption-codes`

- 批量生成兑换码（指定面值、有效期、使用次数上限）。
- 查看兑换码使用状态。
- 禁用或删除未使用的兑换码。

### 3.5 订阅套餐 `/subscriptions`

- 创建、编辑、删除订阅套餐（周期、配额、价格）。
- 查看用户订阅状态，手动调整或取消订阅。

### 3.6 日志（全量）

管理员版日志与普通用户日志页面相同，但可查看**所有用户**的调用记录，并支持按用户 ID 过滤。

## 4. 超级管理员功能

需要 `role = 100`。通过顶部的**工作区切换器**进入「系统设置」工作区，有独立侧边栏。

### 4.1 通用设置

| 子项 | 内容 |
|------|------|
| 系统信息 | 版本号、运行时信息 |
| 配额设置 | 新用户默认配额、邀请奖励配额 |
| 定价展示 | 控制定价页的显示内容 |
| 签到设置 | 每日签到奖励额度 |
| 系统行为 | 注册开关、邮箱验证、邀请码必填等 |
| 渠道亲和性 | 配置渠道亲和缓存策略 |

### 4.2 认证设置

| 子项 | 内容 |
|------|------|
| 基本认证 | 账号密码登录开关、密码强度要求 |
| OAuth 集成 | 配置 GitHub / Discord / LinuxDo / OIDC 应用 ID 与密钥 |
| Passkey | 全局启用 / 禁用 Passkey 登录 |
| Bot 防护 | 集成 Turnstile / reCAPTCHA 等验证码服务 |
| 自定义 OAuth | 添加任意 OAuth 2.0 兼容的第三方登录提供商 |

### 4.3 请求限制

| 子项 | 内容 |
|------|------|
| 速率限制 | 配置全局 / 分组 QPM、TPM 限制 |
| 敏感词过滤 | 维护敏感词列表，命中后拦截请求 |
| SSRF 防护 | 配置可信 IP / 域名白名单 |

### 4.4 内容设置

| 子项 | 内容 |
|------|------|
| 数据大盘 | 系统级总调用量、收入等汇总统计 |
| 公告 | 编辑展示在首页的系统公告 |
| API 地址展示 | 配置展示给用户的 API Base URL |
| FAQ | 管理常见问题列表 |
| Uptime Kuma | 接入状态监控页面 URL |
| 聊天预设 | 全局聊天预设模板管理 |
| 绘图设置 | 默认绘图参数、任务超时配置 |

### 4.5 集成设置

| 子项 | 内容 |
|------|------|
| 支付网关 | 配置 Epay / Stripe / Creem / Waffo 的密钥、回调地址 |
| SMTP 邮件 | 配置发件服务器，用于验证码邮件发送 |
| Worker 代理 | 配置 CF Worker 反向代理地址 |
| io.net 部署 | 配置 io.net GPU 部署集成 |
| 监控告警 | 配置渠道异常告警通知（Webhook / 邮件） |
| Ark 资产 | 配置火山引擎 Ark 多模态资产服务 |

### 4.6 模型设置

| 子项 | 内容 |
|------|------|
| 全局模型配置 | 默认上下文长度、全局模型过滤规则 |
| Gemini 设置 | 安全过滤、区域配置 |
| Claude 设置 | Thinking 预算、模型映射 |
| Grok 设置 | 特定参数配置 |
| 定价比例 | 各模型的输入/输出 Token 计费比例（支持同步上游） |

### 4.7 维护

| 子项 | 内容 |
|------|------|
| 更新检查 | 检测是否有新版本可用 |
| 日志清理 | 按条件批量删除历史日志记录 |
| 头部导航配置 | 自定义顶部导航栏链接 |
| 侧边栏模块 | 控制各功能模块在侧边栏的显示/隐藏 |
| 性能设置 | 磁盘缓存大小、Go GC 策略、连接池参数 |

### 4.8 其他超级管理员专属操作

- **查看渠道密钥**：需要二次安全验证才能明文查看 API Key。
- **全局比例同步**：从 One API 或其他来源拉取模型定价比例。
- **系统级性能指标**：查看实时 CPU、内存、磁盘使用情况，执行 GC。
