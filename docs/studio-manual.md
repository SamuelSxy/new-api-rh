## 1. 页面概览

创意控制台是一个多模态 AI 内容创作工作台，支持四种创作类型，通过顶部 Tab 切换：

| Tab | 功能 | 调用接口 |
|-----|------|----------|
| 生成脚本（Script） | AI 流式输出文本/脚本内容 | `/pg/chat/completions` (SSE) |
| 生成图片（Image） | AI 文生图 / 图生图 | `/v1/images/generations` |
| 生成配音（Voice） | AI 文字转语音 | `/v1/audio/speech` |
| 生成视频（Video） | AI 文生视频 / 图生视频 | `/v1/video/generations` |

每个 Tab 共用同一套交互模式：**选择模型 → 填写参数 → 输入提示词 → 点击生成 → 查看结果**。

## 2. 普通用户功能

### 2.1 生成脚本

用于 AI 流式生成文本内容，如创意脚本、文案、对话等。

**操作步骤：**
1. 在 Tab 顶部下拉框中选择要使用的语言模型。
2. 根据管理员配置的表单字段（如温度、最大 Token 等），按需调整参数。
3. 在底部提示词输入框中输入创作需求（如「写一段 30 秒的产品介绍脚本」）。
4. 点击**生成**按钮，内容以流式方式逐字显示在结果区域。
5. 点击**停止**按钮可随时中断生成。

**注意：**
- 脚本生成消耗 Token 配额，与普通 API 调用计费相同。
- 结果不会自动保存，需手动复制。

---

### 2.2 生成图片

用于 AI 文生图或图生图，支持异步任务轮询。

**操作步骤：**
1. 选择图片生成模型（默认 `rhart-image-n-pro-official/edit`）。
2. 填写扩展参数（视管理员配置而定），常见参数包括：
   - **参考图片**：上传一张或多张参考图（图生图模式）
   - **宽高比**：1:1 / 4:3 / 3:4 / 16:9 / 9:16
   - **分辨率**：1k / 2k / 4k
3. 在提示词框输入图片描述，点击**生成**。
4. 系统提交任务后自动轮询进度，完成后图片显示在结果区域。
5. 右键图片可另存为本地文件。

**注意：**
- 图片生成为异步任务，通常需要数秒至数十秒，请耐心等待。
- 参考图片会自动转换为 Base64 格式发送。

---

### 2.3 生成配音

用于 AI 文字转语音，支持多种音色和调音参数。

**操作步骤：**
1. 选择语音模型（默认 `rhart-audio/text-to-audio/speech-2.8-turbo`）。
2. 常见可调参数（视管理员配置而定）：

   | 参数 | 说明 | 默认值 |
   |------|------|--------|
   | Voice（音色） | 发音人 ID，如 `Elegant_Man` | Elegant_Man |
   | Speed（语速） | 0.25 ~ 4 倍速 | 1.0 |
   | Volume（音量） | 0 ~ 2 | 1.0 |
   | Pitch（音调） | -12 ~ +12 半音 | 0 |
   | Emotion（情绪） | 如 `happy`、`calm` | happy |
   | Response Format | mp3 / wav / pcm | mp3 |
   | English Normalization | 英文数字朗读规范化 | 关闭 |

3. 在提示词框中输入要朗读的文字，点击**生成**。
4. 完成后音频播放器出现在结果区域，可在线试听或下载。

---

### 2.4 生成视频

用于 AI 图生视频或文生视频，任务时间较长，带进度条提示。

**操作步骤：**
1. 选择视频模型（如 Seedance 2.0 / Seedance 2.0 Fast / Happyhorse 等）。
2. 常见可调参数（视管理员配置而定）：

   | 参数 | 说明 | 示例 |
   |------|------|------|
   | Resolution（分辨率） | 480p / 720p / 1080p | 720p |
   | Images（参考图片） | 上传 1~10 张图片，自动转 Base64 | — |
   | Reference Video URL | 可选，参考视频链接 | — |
   | Duration（时长） | 4 ~ 15 秒 | 8 秒 |

3. 输入创作描述，点击**生成**。
4. 进度条显示预估完成百分比（使用渐近估算，实际完成时跳至 100%）。
5. 视频生成完毕后在结果区域显示播放器，可在线预览或下载。

**注意：**
- 视频生成耗时通常为 30 秒至几分钟，期间请勿关闭页面。
- 不同模型支持的分辨率和时长范围不同，以页面下拉选项为准。

---

### 2.5 素材库

素材库是个人私有资源仓库，用于管理上传的图片和视频，方便在创作中复用。

**打开方式：** 在图片或视频 Tab 的参考图上传区域点击「从素材库选择」按钮。

**功能：**

| 操作 | 说明 |
|------|------|
| 上传素材 | 点击上传按钮，选择本地图片（`image/*`）或视频（`video/*`） |
| 浏览素材 | 按图片 / 视频分 Tab 展示，显示缩略图和文件名 |
| 选用素材 | 点击素材卡片上的「使用」按钮，将其填入当前表单的参考资源字段 |
| 删除素材 | 点击素材卡片上的删除图标，二次确认后永久删除 |

**注意：**
- 素材库为当前用户私有，其他用户无法查看。
- 支持 Ark 资产同步状态（`syncAssetArkStatus`），若素材来源于火山引擎 Ark 服务，状态会自动更新。

## 3. 管理员专属功能

> **访问条件**：`role ≥ 10`（管理员或超级管理员）。  
> **位置**：Studio 页面顶部，普通用户不可见。

管理员面板用于为各创作类型配置可用模型及对应表单结构（Schema），控制用户看到哪些模型和哪些参数。

### 3.1 模型配置管理

为脚本 / 图片 / 配音 / 视频四种类型分别维护一套可用模型列表。

**操作步骤：**
1. 在管理面板顶部切换要管理的类型（Script / Image / Voice / Video）。
2. **选择已有模型**：左侧下拉框列出当前该类型已配置的所有模型，点击选中后右侧表单自动填充。
3. **新增模型**：
   - 在「模型 Key」下拉框中选择一个已在「渠道管理」中配置好的模型。
   - 填写「显示名称」（对用户展示的友好名）和「描述」（可选）。
   - 设置状态（启用 / 禁用）。
   - 点击**保存模型**。
4. **修改模型**：选中已有模型 → 修改字段 → 点击**保存模型**。
5. **删除模型**：选中已有模型 → 点击**删除模型**，二次确认后移除（仅删除 Studio 配置，不影响渠道模型本身）。

**注意：**
- 「模型 Key」必须来自已在渠道管理中配置的模型，选择未配置的模型会报错。
- 禁用的模型不会在用户侧的模型下拉框中出现。

---

### 3.2 表单 Schema 管理

每个模型可以绑定一份 JSON Schema，定义用户在该模型下看到的参数表单字段。

**操作步骤：**
1. 在模型选择器中选中目标模型，右侧 Schema 编辑区会自动加载该模型已保存的 Schema（若有）。
2. 在 JSON 编辑框中直接编写或修改 Schema，格式示例：

   ```json
   {
     "name": "My Image Form",
     "modelType": "image",
     "modelName": "my-model-name",
     "fields": [
       {
         "key": "aspect_ratio",
         "label": "Aspect Ratio",
         "type": "select",
         "options": [
           { "label": "1:1", "value": "1:1" },
           { "label": "16:9", "value": "16:9" }
         ],
         "defaultValue": "1:1"
       }
     ]
   }
   ```

3. 点击**保存 Schema**，系统会校验 JSON 格式，通过后保存。
4. **删除 Schema**：点击**删除 Schema**，二次确认后移除（模型仍保留，用户将使用默认内置表单）。

**支持的字段类型（`type`）：**

| 类型 | 渲染形式 |
|------|---------|
| `text` | 单行文本输入框 |
| `textarea` | 多行文本输入框 |
| `number` | 数字输入框（支持 `min`/`max`/`step`） |
| `select` | 下拉选择框（需提供 `options` 数组） |
| `switch` | 开关切换 |
| `image_upload` | 图片上传（支持 `max` 限制张数） |
| `asset_uri` | 从素材库选择资产 URI |

---

### 3.3 一键载入预设

管理面板提供内置预设，可快速填充常用模型和 Schema 配置，无需手动编写 JSON。

**内置预设清单：**

| 类型 | 预设名称 | 模型 Key |
|------|---------|---------|
| 图片 | RunningHub Image Edit | `rhart-image-n-pro-official/edit` |
| 配音 | RunningHub Speech 2.8 Turbo | `rhart-audio/text-to-audio/speech-2.8-turbo` |
| 视频 | Seedance 2.0 Fast | `seedance2.0-fast` |
| 视频 | Seedance 2.0 | `seedance2.0` |
| 视频 | Happyhorse | `happyhorse` |

**操作步骤：**
1. 切换至对应类型 Tab（如 Video）。
2. 点击**载入预设**按钮，从弹出列表中选择目标预设。
3. 表单和 Schema 编辑框自动填入预设内容。
4. 按需微调后点击**保存模型**和**保存 Schema**。

## 4. 通用操作说明

### 任务状态说明

图片、配音、视频均采用**异步任务**模式，提交后系统自动轮询：

| 状态 | 说明 |
|------|------|
| 提交中 | 请求已发送，等待服务端接受 |
| 处理中 | 任务排队或生成中，显示进度/状态文字 |
| 完成 | 结果已返回，显示图片 / 音频 / 视频 |
| 失败 | 生成出错，显示错误提示 |

### 模型加载顺序

每个 Tab 切换时，系统按以下优先级加载模型列表：
1. 从 `/api/studio/models?model_type=<type>` 获取管理员配置的模型列表。
2. 若该类型没有配置任何模型，则回退到用户有权限访问的全部模型（`/api/user/models`）。
